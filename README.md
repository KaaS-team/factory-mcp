# factory-mcp

This was an MCP server that let an MCP client list, create, hand off and steer tasks and runs in a KaaS factory.

It is archived. The Go factory replaced it.

The same tools now ship in `factory mcp` (stdio, or `--http` with a bearer token) in [KaaS-factory](https://github.com/KaaS-team/KaaS-factory), soon KaaS-team/factory.

See [PARITY.md](PARITY.md) for each feature and where it lives now.
